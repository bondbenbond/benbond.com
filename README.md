# benbond.com

A lightweight, responsive personal website for Ben Bond.

## Run locally

The site has no build step or runtime dependencies. Serve the repository root with any static file server:

```sh
npx serve .
```

Then open the local URL printed in the terminal.

## Deployment

Publish `index.html`, `favicon.svg`, and the `assets/` directory. Repository-only files such as this README do not need to be copied to the web root.
